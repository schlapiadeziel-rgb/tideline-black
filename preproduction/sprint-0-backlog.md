# Sprint 0：湾岸城垂直切片生产冲刺

## 冲刺目标

在不扩张地图的前提下，完成一个可在 UE5 中启动、移动、观察和评审的滨海街区灰盒，并同步完成正式主角、车辆和关键建筑的资产规格。冲刺结束不追求完整玩法，而追求团队可以用同一套标准开始生产。

## P0：必须完成

| 编号 | 工作项 | 完成定义 |
|---|---|---|
| P0-01 | UE5 工程初始化 | 项目、版本控制、目录结构、输入映射和基础第三人称模板可启动 |
| P0-02 | 街区灰盒 | 停车楼、滨海主街、夜市入口、水族馆后门和两条侧巷可步行连通 |
| P0-03 | 主角规格 | 完成比例图、正侧背三视图、色彩、服装部件和基础动作清单 |
| P0-04 | 主车辆规格 | 完成外观设计、尺寸、座舱、轮胎、灯组和碰撞体定义 |
| P0-05 | 任务流程图 | 从停车楼出发到水族馆交货的状态、触发器和失败条件明确 |
| P0-06 | 性能预算 | 记录目标平台、帧率、材质、灯光、粒子和 NPC 数量预算 |

## P1：紧接着完成

- 主角低模、拓扑和绑定测试
- 车辆可驾驶灰盒
- 近景街区模块化建筑套件
- 任务目标标记与交互提示
- 黄昏、夜晚两套灯光预设
- 一组原创招牌和街道道具
- 基础环境音循环

## P2：暂不做

- 整座海岛
- 多人联机
- 大量武器和战斗技能
- 复杂经济系统
- 完整警察系统
- 远景区域的最终资产
- 商店、支付和在线账号

## 评审顺序

先评审街区动线，再评审主角和车辆轮廓，再评审光照和镜头，最后评审任务可玩性。任何一个 P0 项目未通过，都不进入下一轮扩张。

## 冲刺产出

1. 可启动的 UE5 预制作工程。
2. 灰盒街区可步行路线。
3. 主角和车辆资产设计包。
4. 一张任务流程图。
5. 一份性能预算表。
6. 一段不超过 3 分钟的内部评审录屏。

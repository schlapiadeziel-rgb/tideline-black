# 《潮汐禁区》首个 3A 垂直切片设计简报

## 目标

制作一个 10–15 分钟、可以独立展示的滨海城市街区切片。切片必须让玩家在第一次游玩时感受到完整的镜头、美术、角色、车辆、任务、音效和反馈闭环，而不是只有一个可走动的灰盒地图。

## 场景范围

切片区域名为“湾岸城·潮汐街区”，包含一条滨海主街、两条侧巷、一座停车楼、一个夜市码头入口和一处废弃水族馆外墙。地图规模控制在步行 5 分钟内可横穿，所有镜头都围绕可见地标组织。

## 玩家流程

1. 玩家在雨后黄昏的滨海停车楼醒来。
2. 通过第三人称移动前往街角联络点。
3. 与原创 NPC“岚”对话，接受“蓝潮货单”。
4. 步行穿过夜市，找到一辆可驾驶的原创街头跑车。
5. 驾车穿过潮汐街区，躲开巡逻车辆，到达旧水族馆后门。
6. 触发一段短演出：霓虹、海雾、远处船灯和 NPC 对话共同完成交货氛围。
7. 玩家返回滨海停车楼，获得奖励并解锁下一阶段入口。

## 必须完成的系统

| 系统 | 切片验收标准 |
|---|---|
| 第三人称移动 | 行走、奔跑、跳跃、镜头跟随、碰撞稳定 |
| 角色表现 | 基础待机、行走、奔跑、上车、下车和受击反馈 |
| 驾驶 | 进入/离开车辆、转向、刹车、碰撞、摄像机切换 |
| NPC | 对话、站立待机、简单巡逻、触发区域行为 |
| 任务 | 接取、目标追踪、阶段切换、失败与重试、奖励反馈 |
| 环境 | 动态海雾、雨后路面、霓虹反射、街灯、交通和海面 |
| UI | 任务卡、目标标记、交互提示、暂停、设置和存档 |
| 音频 | 环境底噪、脚步、车辆、雨声、交互提示和任务音乐 |

## 质量门槛

切片不以地图大小作为通过条件，而以“镜头中是否出现临时资产”为主要判断标准。主角、主车辆、街区主立面、关键 NPC 和任务演出必须使用正式资产；临时灰盒只允许出现在玩家不会近距离观察的背景区域。

首次评审需要录制一段完整无剪辑流程，包含从启动、接任务、驾驶到交付的全过程。评审重点为：视觉统一性、镜头构图、操作反馈、任务可读性和性能稳定性。

## 性能目标

首发开发目标为 PC/主机级质量，垂直切片以 60 FPS 为目标；同时保留后续高端移动端适配可能，但不为了当前 APK 过早牺牲资产质量。每次评审必须记录平均帧率、1% low、显存占用、加载时间和崩溃情况。

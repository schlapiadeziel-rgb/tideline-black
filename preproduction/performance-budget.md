# 垂直切片性能预算

## 目标平台

第一阶段以 PC/主机级体验为目标，目标帧率 60 FPS。移动端适配暂不作为首个切片的质量上限，但所有系统都要保留可降级开关。

## 初始预算

| 项目 | 目标预算 |
|---|---:|
| 运行帧率 | 60 FPS |
| 画面 1% low | 不低于 45 FPS |
| 同屏重要 NPC | 8–12 |
| 同屏交通车辆 | 6–10 |
| 任务区域可见动态光源 | 12–20 |
| 近景 4K 材质 | 仅主角、主车辆和关键建筑使用 |
| 过场加载等待 | 目标低于 5 秒 |
| 崩溃率 | 内部测试版本为 0 个阻塞性崩溃 |

## 必须记录

每周评审记录 GPU 时间、CPU 时间、显存、内存、Draw Calls、Shader 编译、加载时间和最差帧率。任何新增系统都必须说明它占用的预算，不能只凭主观感觉判断“应该跑得动”。

## 降级策略

移动端或低端设备可关闭体积雾、降低阴影级别、减少交通和 NPC 数量、使用简化反射、减少粒子发射率，并切换到低复杂度材质实例。降级不能删除任务逻辑和核心交互。

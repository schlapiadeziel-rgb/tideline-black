# 《潮汐禁区》视觉圣经初稿

## 核心美术命题

“潮湿的霓虹、热带海风、危险但有生活感的海岛城市。”

整体方向不是简单低多边形，也不是完全写实。角色采用清晰、具有记忆点的动漫比例与轮廓；环境采用高细节建筑、真实材质层次和夸张但受控的色彩；光照承担叙事功能，让玩家一眼分辨安全区域、任务区域和危险区域。

## 色彩系统

| 用途 | 色彩方向 | 使用规则 |
|---|---|---|
| 海水与夜空 | 深蓝、青绿 | 大面积背景，避免纯黑 |
| 任务目标 | 金黄、橙色 | 只用于目标和奖励，不泛滥 |
| 友好交互 | 青色、薄荷绿 | NPC、可用车辆和辅助 UI |
| 危险警戒 | 珊瑚红、洋红 | 警报、追逐、敌对反馈 |
| 角色高光 | 暖白、浅金 | 聚焦脸部和关键动作 |

## 角色规范

主角必须具有可从远景识别的轮廓：短外套、长围巾、非对称肩部装饰和醒目的发色。脸部不追求写实毛孔，而追求眼神、发型、服装轮廓和动作姿态。角色材质采用清晰的主色、阴影色和边缘高光三段式层次，避免材质颜色全部混成一块。

每个重要 NPC 至少需要：正面、侧面和背面轮廓差异；一套主服装；待机、走路、转身、对话和受惊动作；一个能在环境中反复出现的色彩或道具记号。

## 环境规范

建筑不允许只由无装饰立方体组成。每栋近景建筑必须至少有三层信息：结构体、功能部件和生活痕迹。功能部件包括遮阳棚、空调机组、消防梯、雨水管、门窗或招牌；生活痕迹包括晾衣、海报、垃圾桶、路障、停车标记或可见室内光。

街道需要有高低差和可读的动线。道路、护栏、街灯和招牌必须共同指向任务目标。海边区域必须能看到远处船灯、雾层、潮湿反射和风向变化。

## 光照与渲染

白天使用暖色太阳光与青色环境光形成互补；黄昏使用低角度长阴影；夜晚使用霓虹、街灯和车辆灯形成局部光岛。卡通化效果通过受控的明暗分段、边缘线和材质高光实现，不依靠简单提高饱和度代替正式着色器。

近景资产优先保证阴影质量和轮廓线稳定。所有发光招牌必须有实际光晕、反射或雾中散射反馈，否则视为未完成。

## UI 与镜头

镜头采用略高于肩部的第三人称视角，在驾驶时降低高度并扩大视野。任务目标保持在画面可读区域，不能遮挡角色动作。移动端 HUD 可以保留，但 3A 正式版本以键鼠、手柄和主机安全区为第一优先级。

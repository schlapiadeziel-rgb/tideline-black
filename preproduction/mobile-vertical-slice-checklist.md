# 移动端 3A 垂直切片首轮验收清单

## 可玩流程

- [ ] Android 横屏启动，安全区和刘海区域布局正确
- [ ] 首次启动自动选择合理画质档位
- [ ] 左摇杆移动，右侧区域控制视角
- [ ] 跳跃、冲刺、互动按钮在不同屏幕比例下可触达
- [ ] 从停车楼出发，接取蓝潮货单
- [ ] 步行穿过夜市并找到车辆
- [ ] 进入车辆、驾驶、刹车、转向和下车正常
- [ ] 到达水族馆后门，触发交货演出
- [ ] 完成任务、获得奖励、保存进度并可重新开始

## 画面表现

- [ ] 主角从远景仍能通过轮廓识别
- [ ] 车辆车灯、尾灯和湿路面反馈可见
- [ ] 夜市招牌、街灯和海雾形成清晰动线
- [ ] 高端档位没有明显材质闪烁或阴影跳变
- [ ] 中端档位关闭高成本效果后仍保持美术统一
- [ ] 任务目标不会被 HUD 或触控按钮遮挡

## 性能与稳定性

- [ ] 高端设备目标 45–60 FPS
- [ ] 中端设备目标 30–45 FPS
- [ ] 低端设备可以进入并完成基础流程
- [ ] 记录平均帧率和 1% low
- [ ] 记录内存峰值、温度和加载时间
- [ ] 连续游玩 30 分钟无阻塞性崩溃
- [ ] 切后台返回后任务状态不丢失
- [ ] 任务中断、重启和重新进入后可以恢复

## 发布准备

- [ ] APK/AAB 使用正式包名和版本号
- [ ] 更新入口指向固定最新版地址
- [ ] Release 资产和校验值已记录
- [ ] 第三方资产授权记录完整
- [ ] 变更已提交 GitHub 并有可回滚提交

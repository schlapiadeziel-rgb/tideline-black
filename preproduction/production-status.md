# 项目状态

## 当前已完成

当前 Three.js Android 原型已经具备横屏运行、第三人称移动、车辆驾驶、任务循环、NPC、交通、动态昼夜、动漫风 HUD、游戏内下载最新版和公开 GitHub Release。它的定位是移动端玩法原型，不是正式 3A 客户端。

## 正式 3A 项目当前阶段

正式项目处于**预制作 / 垂直切片定义阶段**。已完成路线图、移动端目标、视觉圣经、首个街区简报、资产规格、性能预算、Sprint 0 任务板和移动端 UE5 架构。

## 当前阻塞项

正式 UE5 资产生产需要 Unreal Engine 5 工作站、角色与环境美术工具链、版本控制大文件存储以及至少一个可执行的美术/程序协作团队。当前 Sandbox 继续用于文档、原型和自动化验证，不把它伪装成 UE5 编辑器环境。

## 下一次正式评审的通过条件

必须有一个可以在高端 Android 上运行的正式街区切片，完成移动输入、主角、车辆、任务和一段完整演出；同时提供中端画质降级，并记录帧率、内存、加载时间和稳定性数据。未达到这些条件前，不进入整岛扩张。

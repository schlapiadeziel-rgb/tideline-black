# 移动端输入与 HUD 规格

## 横屏布局

游戏固定横屏。左下区域为移动摇杆，右下区域为动作按钮组，右上区域为暂停、任务信息和设备状态提示，中上区域为方向目标和距离。所有按钮遵守安全区，避开刘海、圆角和系统手势区域。

## 玩家状态按钮

| 状态 | 主要按钮 | 次要按钮 |
|---|---|---|
| 步行 | 互动、跳跃、冲刺 | 镜头灵敏度区域 |
| 近距离交互 | 互动按钮高亮 | 取消/后退 |
| 驾驶 | 油门、刹车、转向、手刹 | 下车、镜头 |
| 任务演出 | 跳过、继续 | 无 |
| 暂停 | 继续、重试、设置、下载更新 | 返回标题 |

## 触控规则

互动按钮只有在附近存在有效目标时高亮。按钮需要支持按下、长按和取消状态，但首个切片只使用短按和长按互动，不使用复杂手势。摇杆输入使用死区和边缘缓冲，避免玩家手指轻微抖动导致角色不断转向。

## HUD 层级

任务目标始终优先于装饰信息。目标距离、方向和当前阶段必须在 1 秒内读懂。驾驶时速度、车辆状态和下车按钮优先；步行时隐藏无关车辆信息。演出期间 HUD 降低透明度，但不能隐藏跳过按钮。

## 可访问性

提供按钮尺寸放大、震动开关、字幕大小、字幕背景、色弱友好目标标记和左手模式。关键目标不能只用颜色区分，必须同时使用图标、形状或文字。

## 输入抽象

所有操作映射到统一动作：`Move`、`Look`、`Jump`、`Sprint`、`Interact`、`EnterExitVehicle`、`Throttle`、`Brake`、`Handbrake`、`Pause`。触屏、手柄和键鼠只提供输入，不直接修改任务状态。
